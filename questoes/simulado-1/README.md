# Simulado 1 — Databricks Data Engineer Associate

Simule a prova real em condições cronometradas antes da data do exame.

## Instruções

| Detalhe | Valor |
| ------ | ----- |
| Total de questões | 45 |
| Tempo limite | 90 minutos |
| Meta | 70 %+ (32 ou mais acertos). A Databricks não publica a nota de aprovação |
| Formato | Múltipla escolha, uma única resposta correta |

## Distribuição por domínio

As questões seguem os 7 domínios do exam guide de agosto de 2026, na proporção dos pesos oficiais.

| Domínio | Peso oficial | Questões |
| ------ | :---: | :---: |
| Databricks Intelligence Platform | 6 % | 3 |
| Data Ingestion and Loading | 21 % | 9 |
| Data Transformation and Modeling | 22 % | 10 |
| Working with Lakeflow Jobs | 16 % | 7 |
| Implementing CI/CD | 10 % | 5 |
| Troubleshooting, Monitoring, and Optimization | 10 % | 4 |
| Governance and Security | 15 % | 7 |
| **Total** | **100 %** | **45** |

## Como fazer

1. **Recomendado:** abra o [site de estudos](../../site/index.html) → **Simulados** → *Simulado 1*. O cronômetro, a correção e o relatório por domínio são automáticos
2. Ou, offline: ligue um timer de 90 minutos e abra [questions.md](./questions.md)
3. Responda tudo sem consultar notas ou documentação
4. Só veja a resposta depois de decidir a sua
5. Calcule a nota por domínio para identificar pontos fracos
6. Revise as [dicas para a prova](../../conteudo/recursos/dicas-prova.md) se ficar abaixo de 70 %

## Guia de pontuação

| Acertos | Resultado | Ação |
| ----- | ------ | ------ |
| 36–45 (80–100 %) | Excelente — pronto para a prova | Agende o exame |
| 32–35 (71–79 %) | Passando — revise os pontos fracos | Revise os tópicos errados, faça o Simulado 2 |
| 28–31 (62–70 %) | Perto — estudo focado necessário | Estude os domínios fracos, refaça em 1 semana |
| Abaixo de 28 (< 62 %) | Ainda não — revisão geral necessária | Revise todo o conteúdo antes de tentar de novo |
