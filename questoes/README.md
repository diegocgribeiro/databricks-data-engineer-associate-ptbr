## Como usar os arquivos `.md`

- As respostas ficam em blocos recolhíveis `> [!success]- Answer` (no Obsidian) — no GitHub elas aparecem como citação logo abaixo da questão, então cubra a resposta antes de ler
- Faça primeiro a questão, **só depois** leia a resposta
- Questões marcadas com ⚠️ têm respostas geradas com IA no repositório original — confirme na [documentação oficial](https://docs.databricks.com)
